# IBM VGA artwork font

`ibm-vga-9x14.ttf` is an unmodified copy of `Px437_IBM_VGA_9x14.ttf` from [VileR's Ultimate Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/), obtained from the [ASCII Motion repository](https://github.com/CameronFoxly/Ascii-Motion/blob/main/public/fonts/Px437_IBM_VGA_9x14.ttf).

Font adaptations and enhancements by **VileR**, licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Original raster character designs belong to their respective designers. See the [original documentation and license notice](https://int10h.org/oldschool-pc-fonts/readme/#legal_stuff).

The file is unchanged; only its filename is shortened. It is used exclusively for the Birds illustration, matching its original VGA typography. Persian website text continues to use Vazirmatn. This font's license is separate from the site's code license.
